# SnapImg

Resize, nén, convert nhiều ảnh (JPEG / PNG / WebP / AVIF).

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Tính năng

- Upload nhiều ảnh
- Max width + Max size (KB)
- Convert format + đổi đuôi file
- Tải từng ảnh hoặc ZIP

## Docker

```bash
docker build -t snapimg .
docker run -p 3000:3000 snapimg
```
